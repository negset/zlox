# Zlox

![zig 0.16.0](https://img.shields.io/badge/zig-0.16.0-F7A41D?style=for-the-badge&logo=zig)
![WebAssembly](https://img.shields.io/badge/WebAssembly-654FF0?style=for-the-badge&logo=webassembly&logoColor=white)

A Zig implementation of the [Lox language](https://craftinginterpreters.com/) VM.

## Playground

You can run Zlox on the [web playground](https://negset.com/zlox/).

## Build

- Native

  ```
  $ zig build
  ```

- Wasm

  ```
  $ zig build wasm
  ```
